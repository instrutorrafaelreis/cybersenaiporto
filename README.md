# 🛡️ Cyber SENAI Porto — Treinamento WorldSkills Cyber Security

Plataforma de treino interativa para a **Skill 54 (Cyber Security)** do WorldSkills.
Material didático do **Instrutor Rafael Reis**.

> Site estático (uma página). Acesse pelo GitHub Pages: **https://instrutorrafaelreis.github.io/cybersenaiporto/**

---

## 📚 O que é

Um guia de campo + laboratório de prática que cobre os principais pilares de uma
competição de cibersegurança. Cada comando é ensinado no formato:

**O que é / por que importa → Como fazer → Como verificar → 🔴 Antes / 🟢 Depois → 🎮 Treinar**

O modo **🎮 Treinar** é um terminal simulado: o aluno executa o comando, vê a
vulnerabilidade, digita a correção e testa de novo — sem tocar em sistema real.

## 🗂️ Provas

| Prova | Tema | Pilar |
|-------|------|-------|
| **A** | Enterprise Security & Hardening | Defesa / Hardening (Linux, Windows/AD, PKI, VPN, Logs) |
| **B** | Vulnerabilidades de Sistema Operacional | Ofensivo / Vulnerability Assessment (Linux, Windows, Web, CVSS) |
| **C** | Resposta a Incidentes & Forense Digital | DFIR / SOC |
| **D** | Blue Team, Detection Engineering & SIEM/XDR | Detecção (Sigma, Telemetria, FIM, Resposta Ativa) |
| **E / F** | — | Reservadas para futuros temas |

Cada prova tem abas de conteúdo, uma seção de **Fundamentos** (conceitos clicáveis),
**Ferramentas** e uma **Arena de Provas Simuladas**.

## ✨ Recursos

- **123+ laboratórios interativos** ("Treinar") e **3 simuladores de prova**.
- **Calculadora de CVSS 3.1** (Prova B).
- **Anti-paste**: força a digitação manual dos comandos (memória muscular).
- Conteúdo em **português**, responsivo, tema escuro.
